# Empfohlene Tools und kostenlose Ressourcen

Rund um Antigravity 2.0 bietet Google ein offizielles Dokumentations- und Codelab-Angebot. Dieses Kapitel ordnet die wichtigsten Quellen ein – mit klarem Vorrang für offizielles Material.

---

## 📚 Offizielle Google-Ressourcen (empfohlener Einstieg)

| Ressource | Inhalt | Kosten |
|---|---|---|
| **antigravity.google/docs** | Offizielle Dokumentation zu Desktop-App, CLI, SDK und Browser-Agent | Kostenlos |
| **Google Codelabs – „Getting Started with Google Antigravity"** | Interaktives Einsteiger-Tutorial für das erste Projekt | Kostenlos |
| **Google Codelabs – „Automated UI Testing with Antigravity"** | Praxisanleitung für Browser-Agent, BrowserMCP und Playwright-Integration | Kostenlos |
| **Google AI for Developers – „Building managed agents"** | Referenz für die Managed Agents API auf der Gemini API | Kostenlos |
| **antigravity.google/blog** | Ankündigungen zu neuen Funktionen (SDK, Browser-Agent, Plattform-Updates) | Kostenlos |

!!! tip "Erste Anlaufstelle"
    Für den Einstieg reichen `antigravity.google/docs` und das offizielle Codelab aus – sie werden direkt mit jedem Antigravity-Update aktualisiert, anders als die meisten Drittanbieter-Guides.

## 🧩 Erweiterungsmöglichkeiten

- **AGENTS.md:** Projektregeln und Architekturvorgaben, funktional identisch zum Pendant im [Antigravity CLI](antigravity-cli-agents-md.md).
- **MCP-Server:** Externe Systeme (Datenbanken, JIRA, GitHub) lassen sich über das Model Context Protocol anbinden – sowohl in der Desktop-App als auch über die SDK-Agenten.
- **Custom Functions:** Über die Managed Agents API lassen sich eigene Python-Funktionen und strukturierte Ausgabeschemata einbinden (siehe [SDK-Kapitel](antigravity-2-sdk-managed-agents.md)).

!!! warning "Drittanbieter-Erweiterungen prüfen"
    Wie bei jedem Agenten mit Datei- und Browserzugriff gilt: Community-Erweiterungen und inoffizielle Browser-Add-ons vor der Installation auf Herkunft und Berechtigungsumfang prüfen. Ein Beispiel sind inoffizielle Mobile-Companion-Erweiterungen für Antigravity, die nicht von Google stammen – vor der Nutzung Quelle und Aktivität des Projekts prüfen.
